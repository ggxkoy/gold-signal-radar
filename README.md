# 金价雷达 · 量化实验室

当前公开站点：[GitHub Pages](https://ggxkoy.github.io/gold-signal-radar/)。生产页面位于 `mirror-site/`；`app/` 是早期 Sites 版本，当前量化更新部署到 GitHub Pages。

## Q1：低价回升确认，纯模拟

默认虚拟本金 ¥10,000，不连接真实账户。国际现货金乘美元兑人民币汇率，再除以31.1034768，得到人民币/克参考价；不是积存金、ETF或金店的可执行报价。

满足三项条件后，等待下一笔报价模拟买入：价格 <930元/克、较约6小时前上涨至少3.8元/克、超过过去24小时采样均价。至少4个点且覆盖18小时，6小时参照容忍3小时偏差。不生成补插K线。

买入意向等待超过6小时，或下一价格越过买入/止损/止盈范围则取消。每次最高25%仓位、计划亏损风险0.5%，无杠杆、无做空、不加仓。止损距离为max(2%价格, 7.6元/克)，止盈为1.5倍止损距离，持仓最长10天。手续费默认每边0.10%，滑点每边0.05%，是假设值，真实产品需另行校准。未平仓净值扣预计卖出成本。

观察到止损/止盈时用**当前观察价**成交，不假定恰好在阈值成交，采样空缺和跳空可能超过风险预算。行情源报价超过1小时不更新则暂停新决策。页面即时价与后台账户更新时间分别标明。

## 三种记录分开

- `history.json`：从Git历史恢复的真实采样报价，随后持续追加；每分钟最多一条。不人为补齐。
- `quant-state.json`：固定Q1前向模拟账户和每24小时一次的前向预测。上线前回放不进入该账户；重复运行不会重复成交。参数变更需另开策略版本与台账，不能覆盖历史结果。
- `data.json`：行情/新闻，以及保留原样的旧预测。旧版包含错误的关键词匹配、重复新闻及延迟结算，不纳入新规则成绩。

新24小时预测需价格变化≥3.8元与至少两个来源新闻一致，否则观望。到期后1小时内有有效报价才结算，否则标记缺失。同时公开有效方向命中率、包含震荡的全样本命中率、覆盖率和缺失数。不对旧新闻重新拟合权重来伪造改进。历史回放是探索性模拟，没有独立样本外收益保证。

## 更新与检查

GitHub Actions尝试每15分钟采集并更新纸面账户，但调度可能延迟，应以页面的真实时间戳为准。页面每2分钟尝试刷新国际现货和汇率，**刷新网页不触发账户交易**。

```sh
node --test tests/quant-engine.test.mjs
node scripts/update-pages-data.mjs
python3 -m http.server 3010 --directory mirror-site
```

仅第一次恢复历史时使用 `node scripts/recover-price-history.mjs`，需要完整Git历史。`node scripts/update-pages-data.mjs --offline` 不联网、不会虚构新的价格快照。

评估策略关注扣费收益、25%仓位持有基线、回撤、交易数和未来新增记录。当前历史短且稀疏，不能据此选出可靠最优参数或开展日内高频交易。确定具体交易品种、手续费、账户授权和风险额度后才讨论真实执行。
